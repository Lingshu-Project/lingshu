# 从一页文字开始

把想法，写清楚。

欢迎使用 **灵书 Markdown**。这是一个属于你的写作空间，文件由你直接保存在自己的文件夹中。

## 像写字一样写 Markdown

输入 `#` 后按空格，就能写一个标题。输入 `-` 后按空格，就能列出清单。

- 写下一个想法
- 把长句拆成几行
- 留一点空白，慢慢整理

> 好的文字，往往从一句不完美的话开始。

## 切换视角

点击右上角的「源码」，随时查看 Markdown 文本；再次点击，即可回到排版视图。

| 你想做什么 | 快捷键 |
| --- | --- |
| 打开文档 | Ctrl + O |
| 保存文档 | Ctrl + S |
| 另存为 | Ctrl + Shift + S |
| 切换源码 | Ctrl + / |
| 标题 1 至 6 | Ctrl + 1 至 6 |
| 加粗 / 斜体 / 下划线 | Ctrl + B / I / U |
| 插入代码块 | Ctrl + Shift + K |
| 插入数学公式块 | Ctrl + Shift + M |
| 查找 / 替换 | Ctrl + F / H |
| 导出 PDF / HTML | Ctrl + Shift + E |

## 导出与自己的主题

点击「导出」，可以设置 PDF 的纸张、页边距、横向和页码；HTML 可选择包含样式或大纲。

点击「主题」可导入 CSS，或打开主题目录。正文支持 `#write`，`base.user.css` 可为所有主题添加个人样式。修改 CSS 后点击「刷新」即可看到效果。

通过「编辑 → 语言」或 `Ctrl + ,` 可以切换中文和 English。语言会保存在本机，切换语言不会改写当前文档。

## 也能写一点代码

```javascript
const idea = '把想法写下来';
console.log(idea);
```

这是一份可以编辑的示例。点击「新建」开始空白文档，或点击「保存」把它留在自己的文件夹。
