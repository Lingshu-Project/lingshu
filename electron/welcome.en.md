# Start with a page

Give your ideas room to grow.

Welcome to **Lingshu Markdown**, a space for your writing. Your files stay in the folders you choose.

## Write Markdown naturally

Type `#` followed by a space to create a heading. Type `-` followed by a space to start a list.

- Write down an idea
- Split a long thought into a few lines
- Leave some room to think

> A good page often begins with an imperfect sentence.

## Change your perspective

Click **Source** to see your Markdown text. Click it again to return to the formatted view.

| Action | Shortcut |
| --- | --- |
| Open document | Ctrl + O |
| Save document | Ctrl + S |
| Save as | Ctrl + Shift + S |
| Toggle source | Ctrl + / |
| Heading 1 through 6 | Ctrl + 1 through 6 |
| Bold / Italic / Underline | Ctrl + B / I / U |
| Code block | Ctrl + Shift + K |
| Math block | Ctrl + Shift + M |
| Find / Replace | Ctrl + F / H |
| Export PDF / HTML | Ctrl + Shift + E |

## Export and make it yours

Click **Export** to choose PDF paper size, margins, orientation, and page numbers. HTML exports can include styles and an outline.

Click **Themes** to import CSS or open the theme directory. Use `#write` to style your document. Add shared overrides in `base.user.css`, then click **Refresh** to apply your changes.

Choose **Edit → Language**, or press `Ctrl + ,`, to switch between English and Chinese. Your choice is saved on this computer. Changing the interface language leaves your document untouched.
